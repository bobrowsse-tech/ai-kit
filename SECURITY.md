# Security

## Reporting

Report a vulnerability through a [private security advisory](https://github.com/bobrowsse-tech/ai-kit/security/advisories/new) on this repository. Do not open a public issue for a security report.

## Response

Maintainers aim to acknowledge a report within 3 days and to send a fuller assessment within 14 days. Those are targets for this early stage, not a contractual SLA.

## Scope

In scope: the installer, kit scripts (`scripts/ai/`), guardrail hooks, and shipped template files in this repository as published on npm as `@bobrowsse-tech/ai-kit`.

Out of scope: vulnerabilities in dependencies that do not affect this repository, consumer projects that install the kit, and social-engineering of maintainers.
